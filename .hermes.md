## Frontend — Stack

- **Next.js 15.5** (App Router, React 19, TypeScript 5.9)
- **Tailwind CSS v4** + PostCSS
- **lucide-react** (ícones), **csv-parse** (CSV pt-BR)
- **Scanner**: vit-base-patch16-224 no browser (Transformers.js), index de 5 cartas Base Set

### ⚠️ Como rodar o servidor (CRÍTICO)
- **Sempre**: `cd "C:/Projects/pokescan-tcg/frontend" && npm run dev`
- Usar caminho Windows exato (P maiúsculo) — `cd /c/projects/...` (MSYS minúsculo)
  causa conflito de casing de módulos no Webpack → "invariant expected layout
  router to be mounted" quebra TODAS as páginas
- `npm run dev` (Webpack) formata normal; `next dev --turbo` renderiza SEM CSS
- Porta 3000. Matar órfãos: `MSYS_NO_PATHCONV=1 taskkill /PID <pid> /F`

## Backend — Entry points

### Escoragem
- `script/score_apos_crawl.py --tipo hits|snapshot` — match por liga_id,
  fallback JP (map_jp_to_en_base), fallback nome+número; dedup por liga_id
- Cron: `liga-hits-diario` 07:00 → `liga-hits.sh` (crawler + ensure_embeddings + score)
  `liga-snapshot-semanal` seg 06:00 → `liga-snapshot.sh`
- Wrappers em `~/.hermes/scripts/` e `C:/Models/hermes/scripts/` (manter em sync)

### Cache
- `data/ptcg_cards_cache.json` (20.479 cartas) — paginação global
- `data/img_cache/` (20.509 imagens) — ensure_embeddings mantém incremental
- `data/pokemon_embeddings_base32.csv` — DINOv2-base cls+mean PCA32 (20.426 cartas)
- `data/liga/cache_enrich/cache_enrich_YYYYMMDD.json` — iCO real por carta
- `data/liga/liga_set_sigla_ptcg.json` — mapping set_id ptcg → sigla Liga (233 sets)

## Modelo CatBoost (produção)
- **USD**: MAE $6.46, R² 0.2913 (split temporal honesto, teste 2024+)
- **BRL**: MAE R$29.91, R² 0.2409
- Features: 61 (categorias + cardmarket + arte + supply E1 + 32 embeddings)
- Embeddings: dinov2-base + cls+mean concat + PCA32 (ablações: melhor que small,
  cls puro, pca16/64)
- Re-treino: `script/retrain_models.py` (cache local, sobrescreve .cbm — crons
  carregam a cada execução, seguro)

## Convenções / Pitfalls
- `data/` e `frontend/app/lib` no .gitignore → `git add -f` para versionar
- `experiments/ablation_results.csv` é o changelog de ablações (lido pelo /changelog)
- CSV escorado: colunas sSigla, sNumber, nEN, ed_sNome, real_ref, pred_ref,
  upside_pct, oportunidade, iCO; valores pt-BR com vírgula e entre aspas
- Liga usa numeração JP em sets como 151 (ex: Wartortle 171/165) — sigla MEW
- Cartas de sets sem mapping (Celebrations, McDonald's) NÃO têm link Liga (ligaOk=false)
- Fallback JP: cartas JPR mapeadas por nome para set EN (sem liga_id real)
