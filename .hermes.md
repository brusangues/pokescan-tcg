## Frontend — Arquitetura

### Fluxo do usuário
1. App carrega → baixa modelo Xenova/vit-base-patch16-224 (~50 MB, browser)
2. Busca **5 cartas do Base Set** (base1) via `/api/cards` → pokemontcg.io
3. Gera embeddings das 5 cartas no browser (DINOv2 via Transformers.js)
4. Usuário **faz upload de foto** → browser extrai embedding da foto
5. **Similaridade coseno** contra o index (5 cartas) → mostra a mais próxima

### Stack
- **Next.js 15.4** (App Router, React 19, TypeScript 5.9)
- **Tailwind CSS v4** + PostCSS
- **@xenova/transformers** (DINOv2 `vit-base-patch16-224`) no browser — **sem backend Python**
- **motion** (animação da antiga Framer Motion)
- **react-dropzone** (upload drag and drop)
- **lucide-react** (ícones)
- **@google/genai** "Gemini está na package.json mas não usado diretamente (legacy?)

### API Route (`/api/cards`)
- **Proxy** para `https://api.pokemontcg.io/v2/cards` (evita CORS)
- Suporte opcional a `POKEMON_TCG_API_KEY` via env
- Retry 3x com exponential backoff (1-10s), timeout 15s
- **Bucket**: se a API falhar, lê `public/fetch_result.json`

### Pipeline de embeddings
- Modelo: `Xenova/vit-base-patch16-224` (ViT-B/16, 224px, 768-dim)
- **Singletão**: carrega uma vez no browser e reusa
- Imagens processadas: o pipeline aceita direto URL (inclusive Data URL de file upload)
- Cosine simthilarity implementada manualmente (função pura JS)

### Limitações conhecidas
1. **Index fixo de 5 cartas** — hardcoded query `base1` (Base Set 1999)
2. **Sem embedding de todas as 20.479 cartas** — o index é ínfimo (5 cartas)
3. O nome do modelo é DINOv2 mas Xenova verte `vit-base` (ViT é diferente de DINOv2)
4. Não usa GPU — roda CPU via ONNX runtime no browser
5. CoSamento similarity puro, sem ME (10s de retry) — forma fallback bypass
6. **Não integrado com o backend Python** — roda tudo no browser
7. `fetch_result.json` está vazio/reduzido (fallback de API offline)

## Backend — Entry points

### Escoragem
- `script/score_apos_crawl.py --tipo hits` → escora hits / liga
- `script/score_sets_recentes.py --and 2025` → Cartas subvalorizadas por ano
- Cron: `cronjob("liga-hits-diario")` → `liga-hits.sh` → crawler + score

### Crawler
- `crawler/crawler_liga_hits.py` — raspa 6 combina cões (alta/queda × day/week/month), encheci iCO real por página individual
- `crawler/crawler_liga_snapshot.py` — snapshot semanal de 174 sets
- `crawler/scrapers.py` — seleniza com undetected-chromedriver

### Cache
- `data/ptcg_cards_cache.json` (20.479 cartas, 43 MB) — paginação global
- `data/liga/cache_enrich/cache_enrich_YYYYMMDD.json` — iCO real por carta (memória + disco)
